# Demo media

`showcase-v0.7.0.mp4` is a silent, 22-second compilation of actual application
window recordings. No desktop content or unrelated audio is included.

| Segment | Source |
| --- | --- |
| 0–4 s: Vuron arena | Static view of the game window from the v0.7.0 binary; Vuron is MIT, copyright Varun Verma |
| 4–13 s: Flight Helmet | Rotating model captured from the bundled model viewer; Khronos Flight Helmet is CC0, converted by Gary Hsu |
| 13–18 s: Apple sample | Previously recorded official Metal CPU/GPU synchronization sample; MIT notices retained in demo/apple-sync/upstream |
| 18–22 s: lighting | Previously recorded project cube/material/point-light demo |

`model-rotation.gif` is derived from the same real model-viewer recording.
The input capture is kept locally; captions and cuts do not alter rendered geometry.
`vuron-window.png` and `model-window.png` are real window captures.

See the root THIRD-PARTY-NOTICES.md and each demo's README for source revisions,
licenses, attribution and the distinction between GPU 3D rendering and DOOM's
software frame presented through Metal.
